About the Project

HackMatch AI — Academic AIML Engineering Project

Problem Statement

Forming balanced hackathon teams manually is time-consuming and often results in unbalanced teams with skill gaps, role overlaps, or experience mismatches. There is no systematic way to predict how well a team will perform based on its composition.

Objectives

  • Automatically form balanced teams using participant skills, interests, and experience
  • Match teams to hackathon project requirements
  • Predict team success using an explainable scoring model
  • Generate actionable recommendations for team improvement
  • Demonstrate AI/ML concepts in a real-world application

Methodology

The system follows a pipeline: Participant Data → Feature Extraction → Skill Encoding → Team Formation (greedy optimization) → Success Prediction (weighted scoring) → Recommendation Generation (rule-based). All features are normalized to the 0-1 range. See the Methodology page for details.

Technology Stack

Frontend (Python version): FastAPI + Jinja2 templates
Frontend (React version): React + TypeScript + Vite
Backend: FastAPI (Python) / Supabase Edge Functions
Database: Supabase PostgreSQL
Auth: Supabase Authentication
AI/ML: Custom Python modules (NumPy)
Charts: CSS-based bar charts / Recharts (React)
Styling: Custom CSS (dark AI theme)

Future Scope

  • Replace weighted scoring with a trained ML model (regression/classification)
  • Use clustering algorithms (K-Means, DBSCAN) for team formation
  • Add genetic algorithm or simulated annealing for optimization
  • Train on historical hackathon outcomes data
  • Add real-time collaboration features
  • Integrate NLP for project description analysis

Limitations

  • The weighted scoring model is heuristic, not trained on real data
  • Team formation uses greedy optimization, which may not find the global optimum
  • Prediction scores are estimates, not guaranteed outcomes
  • Recommendations are rule-based, not learned from data
  • Does not account for interpersonal dynamics or communication styles
