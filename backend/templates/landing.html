AI

AI Team Formation

Greedy optimization algorithm that maximizes compatibility, skill coverage, and role diversity while preventing skill clustering.

%

Success Prediction

Explainable weighted scoring model with 6 components, each normalized 0-100 and combined with defined weights for a transparent prediction.

SK

Skill Matching

Binary skill encoding and Jaccard similarity for pairwise compatibility, plus coverage scoring against required project skills.

CH

Analytics Dashboard

Interactive charts showing skill distribution, team scores, experience levels, and role coverage across all generated teams.

REC

AI Recommendations

Rule-based engine that analyzes team composition and generates strengths, weaknesses, and suggested improvements per team.

EX

Export & CSV

Export participant lists, generated teams, scores, and prediction results as CSV files for further analysis or reporting.

About the Project

An academic AIML engineering project demonstrating artificial intelligence and machine learning concepts through a real-world application. The system uses feature extraction, skill encoding, greedy optimization, and explainable weighted prediction — designed so a trained ML model can later replace the scoring component.
